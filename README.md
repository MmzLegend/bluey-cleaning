# Bluey Cleaning Services

Responsive static website for Bluey Cleaning Services, Abuja, Nigeria.

## Contact

Phone and WhatsApp: +234 812 892 0329, confirmed by the owner of this project. The enquiry form opens WhatsApp with a prepared message; visitors review and send it themselves. No enquiry is stored by the site and no booking is automatically confirmed.

## Content

The service categories are an initial presentation of home, office, deep and move-in/move-out cleaning. Scope, pricing and availability are agreed directly with Bluey. No insurance, certification, review or customer-count claims are made. The business-card email and custom domain are props and are not used.

## Editing and hosting

Edit `index.html`, `style.css` and `script.js`. Original SVG illustrations are in `assets/`. Google Fonts supplies DM Sans and Manrope, with local sans-serif fallbacks. There are no build dependencies.

GitHub Pages publishes the root of the `main` branch. All site links and assets use relative URLs for project-page compatibility.
